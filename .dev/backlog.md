# バックログ

`/issue-backlog` と `/issue-unblock` が読み書きするファイルです。

**このファイルはユーザーデータです。** `install.sh --force` で再インストールしても
上書きされません（雛形が入るのは、ファイルが存在しない場合だけ）。

## 使い方

- 「今はやらないが忘れたくない」項目をここに積む
- `/issue-backlog` がブロッカーの無い項目を Issue 化し、この一覧から削除する
- `/issue-unblock` がブロッカーの解消 Issue を作る

## 書式

項目は `### BL-XXX: <タイトル>` で始め、`---` で区切ります。
`/issue-backlog` は「後回しにした理由」を読んでブロッカーの有無を判定するため、
**この見出しは省略しないでください**（省略すると常に「着手不可」と判定されます）。

```markdown
### BL-001: <タイトル>

**概要**: <何をするか>

**後回しにした理由**: <なぜ今やらないか。前提となる実装・確認は何か>

**実装時の考慮点**: <着手する人が知っておくべきこと>

---
```
